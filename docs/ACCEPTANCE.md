# Приёмка по PLAN.md

Дата: 12 октября 2026. Проверяется текущая Python-версия, а не историческое Swift-приложение. Целевые платформы — Windows 11 x64 / NVIDIA RTX 3080 и macOS ARM64. Исходный план Mac → Windows заменён одновременным сопровождением общего ядра и адаптеров. Этот документ перечисляет основания статусов и сохраняет невыполненные критерии.

Обозначения: «реализовано» — функция есть и покрыта указанными проверками; «проверено Windows» — есть свежий запуск на текущей машине; «требует приёмки» — внешние условия ещё не проверены. Тест программного контракта не заменяет нативную проверку другой ОС, редактора или облачного сервиса.

## Свежие доказательства Windows

Последний завершённый автоматический прогон: 238 тестов прошли. Обновлённый интерфейс, обе темы, компактные окна и масштаб 150% описаны в [INTERFACE.md](INTERFACE.md); [отчёт новой сборки](checks/windows-ui.json). [Нативные проверки](checks/windows-native.json) подтверждают ввод, отмену, смену HWND, hotkey и два масштаба. [Первый запуск нового EXE](checks/windows-ui-onboarding.json) сохраняет выбранный CPU до установки. [Прогрев нового самостоятельного приложения](checks/windows-ui-frozen-models.json) выполнен в CPU и GPU с ожиданием завершения процесса и exit code 0; файл содержит имя и SHA256 проверенного пакета. [Отказ по общей GPU-памяти](checks/windows-review-memory.json) восстанавливает OCR; [две настоящие CPU-модели](checks/windows-review-cpu.json) получают предложения и освобождают reviewer. [Windows-замеры](BENCHMARKS.md) содержат методику, числовые результаты и ограничения. [Эксплуатация и сборка](WINDOWS.md) описывают воспроизведение. Текущий обновлённый ZIP: `artifacts/builds/windows-ui/ctrlCctrlV-windows-x64.zip`, рядом SHA256; открытый предыдущий архив и работающая Desktop-копия сохранены.

Быстрое распознавание не означает точного текста: буквальных совпадений на 32 синтетических Windows-областях 0/32, без финального перевода строки 8/32. Экспериментальная модель требует просмотра результата. Эти сведения не скрываются за средним временем или результатами тестов.

## Условия полной приёмки

1. На Mac: создать свежую ARM64-сборку, выполнить source / frozen checks и реальный захват / ввод / hotkeys / permissions, проверить Metal и CPU, готовность / выгрузку и обе OCR-ветки. Исторический Mac-пилот не является подтверждением текущего общего кода.
2. Дополнить ограниченную Windows-проверку OpenRouter согласованными реальными эталонами; проверить медленную сеть и обе OCR-ветки на Mac. Первичный облачный OCR / reviewer, предварительная отмена, отказ HTTP 401 и отмена после отправки тела запроса проверены на одном синтетическом снимке. [Source GUI](checks/windows-openrouter-gui.json) и [прежний опубликованный Windows EXE](checks/windows-frozen-openrouter.json) с нативным захватом / выделением / предпросмотром также проверены. Наблюдаемые задержки 4,562, 11,922 и верхняя оценка 9,437 с превышают цель 4 с. [Клиентская отмена](checks/windows-openrouter-cancel.json) не доказывает остановку вычислений или отсутствие списания у провайдера. Ключ сохранён в Windows Credential Manager и не записывается в проект или диагностические файлы. Использовать недорогие модели в пределах бюджета пользователя.
3. В реальном Cisco VDI записать название / версию клиента, ОС сервера и редакторов; проверить Unicode, код, Tab, пустые строки, длинный фрагмент, отпущенные модификаторы, отмену, потерю фокуса и каждый профиль автоотступа. Заполнить матрицу редакторов.
4. Согласовать диапазон реальных областей и записать полный путь до системного clipboard на обеих ОС / провайдерах, включая простой и медленную сеть. Превышение 4 с фиксируется и не отменяет полный результат.
5. Для публичного распространения отдельно выполнить подпись Windows и подпись / нотарификацию macOS. Для локального пилота это не объявлено обязательным выпуском.

До выполнения внешних пунктов проект имеет рабочий кроссплатформенный код и проверенный Windows-пилот, но полная приёмка плана не завершена. Текущее окружение предоставляет только Windows; доступ к Mac и Cisco не подтверждён. Рабочий ключ OpenRouter настроен; [облачный OCR / reviewer](checks/windows-openrouter.json) проверены в ограниченном Windows-сценарии.
