# Интерфейс приложения

Обновлён 12 октября 2026. Общий интерфейс построен на Qt Widgets для Windows и macOS. Используются системные шрифты, светлая или тёмная палитра ОС; открытые окна реагируют на смену темы.

## Основное окно

Три раздела в постоянной боковой навигации:

| Раздел | Действия |
|---|---|
| Распознавание | Выбор локального OCR или OpenRouter, установка и подготовка модели, GPU / CPU, предпросмотр |
| Печать в VDI | Задержки символов и Enter, обработка Tab, компенсация автоотступов, остановка ввода |
| Система | Разрешения, горячие клавиши, диагностика |

Основное действие, состояние операции, повтор и остановка всегда находятся в нижней панели. Дополнительные параметры моделей раскрываются отдельно. Содержимое раздела прокручивается, навигация и действия остаются доступными. В компактном окне сокращается справка в боковой панели.

Изменённые настройки отмечаются надписью «Есть изменения». «Сохранить» применяет их; запуск действия также сохраняет настройки. Переключатель предпросмотра сохраняется сразу. Во время операции параметры OCR, печати и клавиш недоступны для изменения.

Локальный режим объясняет установку и состояние модели. Облачный режим показывает назначение ключа, отправку снимка и платный характер запросов. Пустое поле ключа сохраняет прежний ключ. Показать можно только новый введённый ключ; при очистке поля маскировка восстанавливается.

## Захват и результат

Выделение области показывает подсказку отмены и физический размер в пикселях. Исходный снимок сделан до появления накладки; подписи не попадают в изображение для OCR.

Результат открывается со снимком слева и редактором справа. Панели можно перераспределить перетаскиванием разделителя. «Вписать» показывает снимок целиком; повторное нажатие возвращает исходный масштаб. Полное изображение сохраняется для проверки моделью.

Редактор содержит номера строк, выбор размера шрифта, отображение пробелов / Tab, визуальный перенос длинных строк, счётчики символов и строк. Эти элементы меняют только отображение. Исходные пробелы, табуляция и переводы строк сохраняются. Python / JSON проверяются без исполнения кода.

OCR автоматически копирует результат. Ручные правки требуют «Копировать текст»; состояние под редактором сравнивает его с последней копией, сделанной приложением, а не отслеживает чужие изменения буфера. Копирование всего результата: `Ctrl+Shift+C` на Windows, `Cmd+Shift+C` на Mac. Обычное копирование выделения остаётся доступным. `Ctrl+Tab` позволяет выйти из редактора клавиатурой; обычный Tab вводит табуляцию.

Проверяющая модель показывает различия и отдельные флажки исправлений. «Применить и скопировать» принимает выбранные изменения; «Отклонить» сохраняет текст. «Исходный текст» восстанавливает OCR, после чего результат нужно скопировать явно. Правки можно отменить стандартной командой редактора.

## Первый запуск и диагностика

Мастер объясняет последовательность работы и выбор места распознавания. Установка моделей и облачные запросы не запускаются самим мастером. Диагностика содержит техническое состояние без снимков, текста, ключей и содержимого буфера.

## Проверка

На Windows прошли 238 автоматических тестов, включая сохранение настроек, маскировку ключа, ограничения во время операции, неизменность текста при переключении отображения и смену системной темы. Подготовлены по 38 синтетических изображений состояний в обеих темах: обычный размер, компактный размер и масштаб 150%. Визуально проверены основные экраны, мастер, предложения проверки, ошибки и ручные правки.

Повторить визуальную проверку без сети и доступа к реальному буферу:

```powershell
.\.venv\Scripts\python.exe -m scripts.render_ui --output artifacts/ui-redesign
.\.venv\Scripts\python.exe -m scripts.render_ui --compact --output artifacts/ui-redesign-compact
```

Нативная проверка обновлённого интерфейса на Mac остаётся частью кроссплатформенной приёмки, описанной в [ACCEPTANCE.md](ACCEPTANCE.md).
