# Состояние разработки и аудит требований

Обновлено 11 октября 2026. Цель — закончить доступные без участия пользователя этапы Mac и подготовить удобный, отзывчивый интерфейс. Проверки на Windows и в Cisco остаются отдельной приёмкой. Цель разработки пока не достигнута. Apple Vision исключён по решению пользователя. Сравнение моделей завершено по текущему решению пользователя; новые эксперименты не запланированы, фокус перенесён на сценарии приложения и устойчивость.

169 автоматических тестов проходят. Это подтверждает покрытые программные контракты, а не совместимость с любым редактором или реальным VDI. Новая тестовая сборка содержит LightOnOCR 4B и проверку текста; установленная копия пользователя обновлена по его явному запросу; резервная копия сохранена в `~/Applications/.ctrlCctrlV-backups/`. Предпросмотр и диагностика отрендерены в обеих темах; системные права эти проверки не затрагивают.

Диагностика доступна в разделе «Система»: сбор в рабочем потоке, предварительный просмотр, ручное копирование и отмена. Поля собираются по разрешённому списку без ключей, изображений, текста, буфера, путей и имени компьютера; отсутствие этих данных проверено тестом. Неопределённые разрешения / память показываются как `null`. Для упакованной Mac-сборки доступны тип подписи и CDHash без пути исполняемого файла и имени владельца сертификата; эти поля проверены тестом и реальным запуском сборки.

Скрипт `python -m scripts.render_ui` сохраняет воспроизводимые макеты всех разделов, облачного режима, предпросмотра, проверки и её ожидания в `artifacts/ui`. Он использует синтетические изображения, не захватывает экран и не обращается к системному буферу. Проверка всегда использует снимок соответствующего предпросмотра, даже если более поздний захват завершился ошибкой; этот случай покрыт тестом.

Следующие автономные работы: устойчивость сценариев захвата, копирования и печати, понятные состояния ошибок и восстановления, отзывчивость интерфейса и подготовка выпуска. Сравнение OCR-моделей завершено по решению пользователя; RapidOCR и варианты квантования остаются экспериментами, каталог и модель по умолчанию не изменены. Целевая скорость 4 секунды на длинных областях не достигнута; это метрика, а не блокирующий срок OCR. Без Windows/Cisco и сертификата продолжается остальная разработка; наличие этих ограничений не означает завершения доступных этапов.

Обновление установленной копии: 128 тестов проходят, smoke упакованного приложения exit 0 (синтаксис, диагностика, вписывание Retina-снимка). Подпись проверена, хеш установленного исполняемого файла совпадает с проверенной сборкой; запуск из `~/Applications` подтверждён процессом. Обновление не изменяет отдельный каталог моделей и настроек. Кнопка «Вписать» в предпросмотре меняет только отображение; исходный снимок для проверки сохраняется.

Последняя отдельная тестовая сборка проверена с корректными и повреждёнными настройками: оба bundled smoke завершились с exit 0. Загрузка настроек ограничена 64 КиБ, проверяет типы и значения и возвращается к значениям по умолчанию при повреждении файла, сохраняя исходный файл. Запись слишком большого файла отклоняется до замены существующего. Добавлены 27 регрессионных случаев; всего 155 тестов. В этой итерации установленная копия пользователя не заменялась.

По уточнению пользователя 4 секунды теперь служат только границей метрики. Первичный OCR не имеет общего таймаута 4 с, продолжает работу и копирует полный результат при превышении; отмена и отклонение неполных ответов сохранены. Прошедшее время показывается во время ожидания и после копирования. Для сетевых зависаний действуют отдельные таймауты подключения / ожидания данных. После ошибок доступен повтор того же снимка с текущими настройками; предыдущий результат предпросмотра не подменяет снимок для повтора.

Проверка последнего изменения: 161 автоматический тест проходит; отдельная ARM64-сборка пересобрана и bundled smoke завершился с exit 0. Состояния медленного OCR и повтора после ошибки отрендерены и проверены в светлой и тёмной темах. Новые модельные прогоны не выполнялись. Установленная копия в `~/Applications` в этой итерации не заменялась.

Сетевое ожидание OCR теперь отменяется через асинхронный HTTP-транспорт внутри фонового потока, без ожидания 120-секундного read timeout. Проверены реальные loopback-соединения при ожидании заголовков и части тела, для локального и облачного режима; соединение закрывается и worker освобождается менее чем за 1 с в тестах. GUI снова включает действия и показывает завершённую отмену вместо постоянного «Остановка…». Старый буфер сохраняется, следующий запрос успешно копирует результат. В `--smoke` добавлена проверка реального loopback-транспорта, результата после цели 4 с и сетевой отмены без обращения к внешнему OCR.

Последняя ARM64-сборка проверена: bundled `--smoke` завершился с exit 0, включая реальный loopback HTTP-транспорт и отмену сетевого ожидания. Полный набор: 166 тестов, все проходят. Установленная копия пользователя в этой итерации не заменялась.

Сохранение настроек отделено от записи API-ключа: ошибка файла не изменяет ключ; ошибка системного хранилища оставляет введённый ключ в поле и явно сообщает о сохранённых параметрах. Ошибка подключения горячих клавиш также показывается отдельно. Три регрессионных сценария проходят; полный набор — 169 тестов.
