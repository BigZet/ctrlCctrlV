# ctrlCctrlV 0.4.2 — надёжность печати, истории и профиля

Предварительный выпуск Rust-приложения после полного ревью. Rust — основная
развиваемая версия; отдельный опубликованный Python-пилот 0.1.1 этим выпуском
не заменяется. Исправления совместимости Python входят в исходники.

## Что изменилось

- **Печать:** пауза между вводом символа и удалением автозакрытия больше не
  повторяет уже отправленный символ. Продолжение восстанавливает контекст
  кавычек и комментариев; callbacks старого запуска не меняют новое задание.
- **Общий профиль:** обновлённые Rust/Python используют совместимую системную
  блокировку. Неизвестные JSON-поля сохраняются обеими версиями.
- **История:** запись и ответы моделей, включая сырые ответы, удаляются одной
  транзакцией. Undo хранится только в памяти 30 секунд и допускает повтор после
  временной ошибки БД. Старая кнопка Undo не отменяет следующее удаление.
- **Настройки:** повреждённый файл нельзя неявно заменить дефолтами. Явное
  восстановление сначала сохраняет точные исходные байты в отдельный файл.
- **OCR:** режимы Авто/Текст/CSV влияют на обработку; целые поддержанные таблицы
  консервативно преобразуются в CSV. Неподтверждённый CSV сопровождается
  предупреждением, исходный ответ не теряется.
- **Движок:** выгрузка по простою не прерывает активный запрос. Ошибка Windows
  Job Object останавливает запуск собственного процесса, а не игнорируется.
- **Метрики и безопасность:** «Скопировано» учитывает PNG, подготовку модели
  и запись буфера; время запроса модели подписано отдельно. Произвольные тела
  ошибок провайдера не попадают в сообщения. Обновлены уязвимые SQLite и
  зависимости проверки сертификатов.
- **Исходники Python:** завершение обоих движков вынесено с GUI-потока;
  периодическая проверка не сканирует файлы моделей; добавлена проверка места
  до распаковки tar-архива.
- **Проверки:** добавлены межъязыковые, межпроцессные и JS smoke-регрессии,
  проверки зависимостей и минимального Rust в CI.

## Скачать и обновить

- **Windows 10/11 x64:** `ctrlCctrlV-0.4.2-windows-x64-setup.exe` для текущего
  пользователя либо `ctrlCctrlV-0.4.2-windows-x64.exe` без установки.
  Переносимому EXE нужен WebView2; установщик загружает его при отсутствии.
- **macOS 13+ / Apple Silicon:** `ctrlCctrlV-0.4.2-macos-arm64.dmg`.
- Контрольные суммы — `SHA256SUMS.txt`.

**Перед обновлением полностью закройте все прежние Rust/Python-копии через
трей.** Старые бинарники не знают нового протокола блокировки и не должны
одновременно работать с обновлённой версией в одном профиле.

Пути настроек, истории, моделей и системного API-ключа не меняются.
Windows-пакеты не подписаны сертификатом издателя; macOS использует ad-hoc
подпись без нотарификации. На Mac после замены приложения может потребоваться
повторно выдать разрешения.

Для сборки из исходников теперь нужен **Rust 1.89+**: это требование исправленной
SQLite-зависимости, а не изменение минимальной версии ОС.

## Проверки и ограничения

До подготовки релиза локально пройдены 134 Rust-теста, 862 Python-теста
(один пропуск), обязательная Python/Rust-совместимость, fmt, Clippy без
предупреждений, Python lint, JS smoke, Windows-сборки и проверка Rust 1.89.
Аудиты зависимостей не выявили известных уязвимостей; предупреждения об
устаревших транзитивных библиотеках остаются видимыми.

Автотесты не подтверждают работу конкретного VDI и редактора. Перемещение
курсора внутри того же окна надёжно не обнаруживается. Ожидающее удаление
автозакрытия можно продолжить только в исходном окне. Уничтожение всех копий
удалённого текста на диске и в чужом буфере не гарантируется.
Между созданием Windows-процесса и привязкой к Job Object остаётся короткое окно.
Платные OCR-запросы и интерактивная нативная приёмка macOS не выполнялись.
