# ctrlCctrlV 0.1.1 — Windows и macOS

Первый выпуск с установочными пакетами для Windows x64 и Mac Apple Silicon.

## Скачать и установить

- **Windows 11 x64:** `ctrlCctrlV-0.1.1-windows-x64-setup.exe`. Запустите мастер установки. Приложение устанавливается для текущего пользователя, без прав администратора; доступен ярлык в меню «Пуск». Удаление — через «Параметры → Приложения». Настройки, история и скачанные модели сохраняются при обновлении и удалении программы.
- **macOS 14+ / Apple Silicon (M1 и новее):** `ctrlCctrlV-0.1.1-macos-arm64.dmg`. Откройте образ и перетащите `ctrlCctrlV.app` в `Applications`. Извлеките образ и запускайте установленную копию. Для первого запуска выдайте запрошенные разрешения в «Системные настройки → Конфиденциальность и безопасность».
- **Windows без установки:** распакуйте `ctrlCctrlV-windows-x64.zip` целиком и запустите `ctrlCctrlV/ctrlCctrlV.exe`. Сохраните соседний каталог `_internal`.

Python устанавливать отдельно не нужно. Модель OCR и движок скачиваются из приложения по кнопке «Скачать модель»; они не включены в установщик. Локально доступны CPU и GPU, для NVIDIA требуется подходящий драйвер. OpenRouter требует собственного API-ключа.

Перед обновлением полностью завершите ctrlCctrlV через меню приложения/трей. Используйте одну установленную копию.

## Что изменилось

- Исправлена запись горячих клавиш macOS с Shift и нелатинской раскладкой.
- Исправлено обрезание списка формата результата в окне «Работа» на Mac.
- Добавлены Windows Setup, macOS DMG, контрольные суммы и проверки установленных копий в GitHub Actions.
- Версия приложения отображается в интерфейсе и метаданных пакета.

## Подпись и ограничения

Это пилотная версия. Windows-пакет не подписан сертификатом издателя; Mac-пакет имеет ad-hoc подпись и не нотарифицирован Apple. Windows SmartScreen или macOS Gatekeeper могут запросить подтверждение. На Mac при блокировке используйте штатное действие «Всё равно открыть» в «Конфиденциальность и безопасность», только если доверяете этому релизу. Системные средства защиты отключать не требуется.

Из-за отсутствия постоянного сертификата Mac после обновления может потребоваться повторно добавить установленную копию в «Универсальный доступ», «Мониторинг ввода» и «Запись экрана».

OCR может ошибаться; проверяйте результат перед вводом. Intel Mac, Windows ARM, Cisco/VDI и несколько мониторов не проверялись в этом выпуске. Контрольные суммы SHA256 приложены к пакетам.
