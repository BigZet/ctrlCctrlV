# Проверка macOS — 13 октября 2026

Проверена версия `27eaec4` с описанными ниже локальными исправлениями на macOS 26.5.1, Apple Silicon ARM64, Python 3.12.14, PySide6 / Qt 6.12.0. Сборка: PyInstaller 6.22.3, ad-hoc подпись.

## Найденные и исправленные проблемы

1. **Запись сочетаний с Shift и зависимостью от раскладки.** Qt Cocoa передаёт символ (`*` вместо физической `8`, кириллическую букву вместо латинской), а глобальные сочетания регистрируются по физическому коду. Запись теперь использует тот же `KEY_CODES`, что и регистрация. Native modifiers отличают нативный код A, равный нулю, от Qt-событий без нативных данных. События отдельных модификаторов и lock-клавиш отбрасываются до преобразования: Cocoa `flagsChanged` тоже может содержать нулевой код, который нельзя считать клавишей A. Добавлен 31 регрессионный случай; 19 из исходных 21 падали до исправления. В собранном нативном окне подтверждена запись `Ctrl+Shift+8` и `Cmd+Shift+8`; исходное сочетание восстановлено.
2. **Обрезание списка «Результат» в окне «Работа».** Нативные отступы macOS у соседнего checkbox оставляли контейнеру списка 29 px при высоте списка 36 px. Checkbox помещён в логическую группу с собственным layout. Проверка с нативным стилем macOS воспроизводила проблему до исправления; после него контролы целиком помещаются при изменении ширины окна. Исправление также проверено визуально в собранной `.app`.
3. **Семь падений переносимых тестов.** Шесть тестов путали Qt `ControlModifier` с физическим Ctrl на Mac (на Mac Qt использует для него `MetaModifier`). Ещё один тест глобально подменял `sys.platform` и вызывал Windows API на Mac. Исправлены события тестов и область подмены платформы; поведение приложения для этих семи случаев не менялось.

```sh
.venv/bin/python -m pytest -q -ra
QT_QPA_PLATFORM=offscreen .venv/bin/python -m ctrlcctrlv --smoke --data-dir artifacts/macos-check/source-final
.venv/bin/python scripts/build_macos.py --development --output artifacts/macos-check/build
artifacts/macos-check/build/dist/ctrlCctrlV.app/Contents/MacOS/ctrlCctrlV --smoke --data-dir artifacts/macos-check/frozen-final
```

Автоматические smoke и OCR-бенчмарк используют отдельный профиль; установленные модели подключены через ссылки. Финальная нативная `.app` запущена macOS с обычным пользовательским профилем. С согласия пользователя для неё предоставлены Accessibility, Input Monitoring и Screen Recording. Нативный OCR использует системный буфер и обычную историю приложения. Установленная копия в `~/Applications` и файлы моделей не заменялись.

Основные сценарии macOS в этом проходе проверены, включая ручное подтверждение печати пользователем. Ранние автоматические попытки печати останавливались защитой от удерживаемых модификаторов или из-за активного окна ctrlCctrlV; они не считаются успешными и не подменяют ручную проверку. OpenRouter, Cisco/VDI и несколько мониторов в этом проходе не проверялись.
